# Code of Conduct

## Our Commitment

We are committed to providing a welcoming and inspiring community for all. Our Code of Conduct explains our expectations for participant behavior and the consequences for unacceptable behavior.

## Expected Behavior

All participants in our community are expected to:

- **Be respectful.** Disagreement is no excuse for poor behavior and poor manners.
- **Be patient.** Remember that people have varying communication styles and that not everyone is using their native language.
- **Be thoughtful.** Remember that decisions are often made difficult by disagreement.
- **Be kind.** Treat others as you want to be treated. Support your fellow community members.
- **Be inclusive.** Our project welcomes and supports people of all backgrounds and identities.

## Unacceptable Behavior

The following behavior is considered unacceptable:

- **Discrimination** based on race, color, gender, gender identity, sexual orientation, national origin, age, disability, or any other characteristic.
- **Harassment** including but not limited to: offensive comments, unwelcome advances, or threats.
- **Hate speech** targeting individuals or groups.
- **Bullying** or intimidation.
- **Sexual or violent** content or conduct.
- **Spam** or advertising.
- **Trolling** or intentionally disrupting discussions.

## Reporting Issues

If you witness unacceptable behavior or have concerns, please report it to the project maintainers:

- **Email:** your-email@example.com
- **GitHub Issues:** [Report via GitHub](https://github.com/YOUR_USERNAME/dermalens-ai/issues/new)

All reports will be kept confidential. We take all concerns seriously and will investigate promptly.

## Enforcement

Violations of this Code of Conduct may result in:

1. **Warning** — A clear explanation of the violation
2. **Temporary suspension** — Removal from discussions for a period
3. **Permanent ban** — Removal from the community

The severity of the response depends on the nature of the violation.

## Scope

This Code of Conduct applies to:

- GitHub repositories
- GitHub discussions and issues
- Pull requests and code reviews
- Project documentation
- Social media accounts
- Any other official channels

## Attribution

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/) and the [Python Community Code of Conduct](https://www.python.org/psf/conduct/).
